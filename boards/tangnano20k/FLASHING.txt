Flashing {project} {version} onto the Tang Nano 20K

{name}.bin holds every game's core at its place in the board's flash. With the
repository (https://github.com/scullymi/game20k), one command downloads, checks
and writes it, see its README:

  python3 g20k.py flash --download {version}

By hand, write it with openFPGALoader (brew install openfpgaloader, apt install
openfpgaloader):

  openFPGALoader -b tangnano20k -f --verify {name}.bin

On Windows, openFPGALoader (and g20k.py) needs the WinUSB driver on the Nano once:
https://github.com/scullymi/game20k/blob/v{version}/docs/windows-usb.md

Gowin's programmer_cli works too, given the full path of the file:

  programmer_cli --device GW2AR-18C --run 32 --mcuFile "$PWD/{name}.bin" --spiaddr 0x000000

If it reports an error, run it once more. It must start at 0x000000: given another
address, programmer_cli erases there but writes at 0x000000.

Power the board off and on afterwards. These cores talk to a Companion on the header.
The firmware of the same version goes onto it: {project}-{version}-firmware-pico2w.zip
for a Pico 2 W, the m0sdock image of {project}-{version}-firmware-bl616.zip for an M0S
Dock. The ROM files go onto the SD card, see https://github.com/scullymi/game20k.
