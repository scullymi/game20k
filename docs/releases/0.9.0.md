The bitstreams of this release come from the free toolchain, built by GitHub Actions from the sources at the tag.

> **Hardware:** a Sipeed Tang Nano 20K and a **Raspberry Pi Pico 2 W**. The firmware runs on the Pico 2 W only.

## Download

- `game20k-0.9.0-pico2w.zip`: the firmware for the Raspberry Pi Pico 2 W.
- `game20k-0.9.0-tangnano20k.zip`: one image for the Tang Nano 20K's flash with all eight cores.

Setup as in the [README](https://github.com/scullymi/game20k/blob/v0.9.0/README.md#quick-start) and `FLASHING.txt`. The SD card of 0.8.x keeps working.

## Changes since 0.8.1

- All eight cores are built with Yosys, nextpnr and Apicula instead of the Gowin IDE, see [docs/OPEN-TOOLCHAIN.md](https://github.com/scullymi/game20k/blob/v0.9.0/docs/OPEN-TOOLCHAIN.md). The Gowin build stays available.
- Both zips come from GitHub Actions, `gh attestation verify <zip> -R scullymi/game20k` confirms their origin.
- The cores also run with the upstream FPGA-Companion firmware on other boards: they send it a short menu, and the ROM loader accepts ROM files with the footer of `make_rom.py`, see [docs/hardware.md](https://github.com/scullymi/game20k/blob/v0.9.0/docs/hardware.md).
