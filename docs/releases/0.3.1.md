Ms. Pac-Man joins Pac-Man and Puck Man on the Pac-Man board.

> **Hardware:** a Sipeed Tang Nano 20K and a **Raspberry Pi Pico 2 W**. The firmware runs on the Pico 2 W only.

## Download

- `game20k-0.3.1-pico2w.zip`: the firmware for the Raspberry Pi Pico 2 W.
- `game20k-0.3.1-tangnano20k.zip`: one image for the Tang Nano 20K's flash with the Galaga core and the Pac-Man core, which runs Pac-Man, Puck Man and Ms. Pac-Man.

## Getting started

1. Prepare the SD card with your own ROM sets and `config.ini`, see [README, steps 2 and 3](https://github.com/scullymi/game20k/blob/v0.3.1/README.md#2-roms).
2. Write the image into the Tang Nano 20K's flash with the command in `FLASHING.txt`, then power the board off and on.
3. Hold BOOTSEL on the Pico 2 W, plug it in and copy the `.uf2` to the drive that appears.

## Changes since 0.3.0

- Ms. Pac-Man (Midway) on the Pac-Man board, with its achievements, leaderboards and Rich Presence on RetroAchievements. `scripts/make_sdcard.sh` builds `mspacman.rom` from the MAME set `mspacman`, and `ROM set` in the menu switches to it.
- One Pac-Man bitstream runs Pac-Man, Puck Man and Ms. Pac-Man. The ROM file decides which game it is.
- `Account` in the menu notes `DIP not default!` when Ms. Pac-Man does not run with 3 lives, the game's default. Seven of its ten leaderboards count with at most 3 lives only.
