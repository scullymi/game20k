Update the cores and the firmware together. The 0.9.4 firmware needs the 0.9.4 cores.

Version 0.9.3 was not released because its BL616 firmware sometimes crashed while loading a game.

## Changes since 0.9.2

- BL616: the firmware no longer crashes while loading a game (#49).
- The cores no longer drop a byte at the end of a transfer from the Companion, so the firmware no longer waits after each one (#41).
- Ghosts'n Goblins: the core now meets timing with more margin (#43).
- `g20k.py` covers every step: `sdcard` prepares the SD card, and `flash --download` and `firmware --download` use the files of a release (#36).
- On Windows, flashing the Nano needs the WinUSB driver (see [docs/windows-usb.md](https://github.com/scullymi/game20k/blob/v0.9.4/docs/windows-usb.md), #39).
- The documentation is reorganized so that each topic has one place (#45), and the gallery shows all games.
