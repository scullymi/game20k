1942 joins as the third core: jotego's jt1942, upright or rotated, with RetroAchievements.

> **Hardware:** a Sipeed Tang Nano 20K and a **Raspberry Pi Pico 2 W**. The firmware runs on the Pico 2 W only.

## Download

- `game20k-0.4.0-pico2w.zip`: the firmware for the Raspberry Pi Pico 2 W.
- `game20k-0.4.0-tangnano20k.zip`: one image for the Tang Nano 20K's flash with the Galaga core, the Pac-Man core (Pac-Man, Puck Man and Ms. Pac-Man) and the 1942 core.

## Getting started

1. Prepare the SD card with your own ROM sets and `config.ini`, see [README, Quick start, step 2](https://github.com/scullymi/game20k/blob/v0.4.0/README.md#quick-start). For 1942, put the MAME set `1942` into `roms/`.
2. Write the image into the Tang Nano 20K's flash with one of the commands in `FLASHING.txt`, then power the board off and on.
3. Hold BOOTSEL on the Pico 2 W, plug it in and copy the `.uf2` to the drive that appears.

1942 runs at 59.64 Hz, the other games at 61.03 Hz. The monitor has to accept both.

## Changes since 0.3.1

- 1942 (Capcom, Revision B) on jotego's jt1942 core, with its achievements and leaderboards on RetroAchievements. `scripts/make_sdcard.sh` builds `1942.rom` from the MAME set `1942`, and `ROM set` in the menu switches to it.
- 1942 keeps its ROM in the SDRAM, next to the frame buffer, so it runs upright (`Upright 2x`) and rotated (`Landscape 3x`) like the other games, both with the full colours of the original.
- 1942 has its own controls (fire on button 1, loop on button 2) and a `Sound` setting: `Soft` tones down the shrill high notes.
- `scripts/make_sdcard.sh` writes one settings file per core: `galaga.ini`, `pacman.ini` and `1942.ini`.
- The flash image can also be written with Gowin's `programmer_cli`, see `FLASHING.txt`.
- New README with screenshots, the build details moved to `docs/BUILD.md`.
