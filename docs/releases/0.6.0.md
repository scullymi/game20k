Eight cores, fifteen games: Vulgus, Pirate Ship Higemaru, Jr. Pac-Man, Time Pilot, Ghosts'n Goblins, Dig Dug, Pang, Super Pang and 1943 Mark II join, plus five regional or speedup sets.

> **Hardware:** a Sipeed Tang Nano 20K and a **Raspberry Pi Pico 2 W**. The firmware runs on the Pico 2 W only.

## Download

- `game20k-0.6.0-pico2w.zip`: the firmware for the Raspberry Pi Pico 2 W.
- `game20k-0.6.0-tangnano20k.zip`: one image for the Tang Nano 20K's flash with all eight cores.

Setup as in the [README](https://github.com/scullymi/game20k/blob/v0.6.0/README.md#quick-start) and `FLASHING.txt`. [roms/README.md](https://github.com/scullymi/game20k/blob/v0.6.0/roms/README.md) lists the MAME sets each game needs. Galaga now also needs `namco51.zip`, so run `scripts/make_sdcard.sh` again.

## Changes since 0.5.0

- Vulgus and Pirate Ship Higemaru on the 1942 core, Jr. Pac-Man on the Pac-Man core, Pang and Super Pang on one core.
- New cores: Time Pilot (Ace's core), Ghosts'n Goblins (jotego's jtgng), Dig Dug (MiSTer-X's core with the 51XX and 53XX running their own programs) and Pang (jotego's jtpang).
- Galaga runs the program of the real 51XX instead of a reconstruction in logic: coins, credits and the stick behave as on the arcade board, and the attract mode ignores the fire button.
- Each manifest says how its game stands (`screen upright`, `cw` or `ccw`). A game with a horizontal monitor always runs 3x with the menu and the banner upright, and its core is built without the frame buffer.
- Pang's banner lies over the top of the picture on a darkened box.
- The menu no longer loses bytes on the way from the Pico to the picture on a core whose clock is not a fraction of the HDMI clock.
- `scripts/make_rom.py` decrypts Kabuki (Pang) and Jr. Pac-Man ahead, and knows header bytes, filler and zero sections.

Pang and Super Pang run in softcore, see Known issues in the [README](https://github.com/scullymi/game20k/blob/v0.6.0/README.md#known-issues).
