The first release with a ready-made firmware image, so the Pico 2 W no longer has to be built from source. The firmware code is unchanged from 0.1.0, it now reports version 0.1.1.

## Download

`game20k-0.1.1-pico2w.zip` holds

- `game20k-0.1.1-pico2w.uf2`, the firmware for the Raspberry Pi Pico 2 W, and
- `NOTICE.txt`, the licences of all software in the image.

GitHub Actions built both from the sources at this tag. The SHA-256 sums are at the end, and `gh attestation verify game20k-0.1.1-pico2w.zip -R scullymi/game20k` checks the build provenance.

The image runs on a Raspberry Pi Pico 2 W only.

## Getting started

1. Prepare the SD card with your own ROM set and `config.ini`, see [README, steps 2 and 3](https://github.com/scullymi/game20k/blob/v0.1.1/README.md#2-roms).
2. Hold BOOTSEL on the Pico 2 W, plug it in and copy the `.uf2` to the drive that appears.

The Tang Nano 20K needs its bitstream as well. This release does not include one, [THIRD-PARTY.md](https://github.com/scullymi/game20k/blob/v0.1.1/THIRD-PARTY.md#not-distributed) explains why. Build and flash it as [README, step 4](https://github.com/scullymi/game20k/blob/v0.1.1/README.md#4-fpga-build-and-flash) describes.

## Status

Galaga runs with picture, sound, the OSD menu, landscape or portrait output and RetroAchievements. Unlocks count as softcore until RetroAchievements approves this client for hardcore mode. The [README](https://github.com/scullymi/game20k/blob/v0.1.1/README.md#status) lists what works and what is open.
