The menu now tells you which DIP switches an achievement set expects, and sets them for you.

> **Hardware:** a Sipeed Tang Nano 20K and a **Raspberry Pi Pico 2 W**. The firmware runs on the Pico 2 W only.

## Download

- `game20k-0.8.1-pico2w.zip`: the firmware for the Raspberry Pi Pico 2 W.
- `game20k-0.8.1-tangnano20k.zip`: one image for the Tang Nano 20K's flash with all eight cores.

Setup as in the [README](https://github.com/scullymi/game20k/blob/v0.8.1/README.md#quick-start) and `FLASHING.txt`. The cores are the same as in 0.8.0, only the firmware changes.

## Changes since 0.8.0

- `Set for RA` in the `DIP switches` menu sets every switch the game's achievement set expects, see [DIP switches](https://github.com/scullymi/game20k/blob/v0.8.1/docs/retroachievements.md#dip-switches).
- The banner reads "DIP NOT AS SET", and `Account` names the switch to change. Dig Dug, Jr. Pac-Man and Puck Man start with factory settings their sets do not expect.
- After a game switch, the banner no longer shows a DIP warning left over from the previous game.
- After a game switch, the mode banner no longer goes missing or shows softcore before hardcore.
