Fixes for RetroAchievements after a game switch and for the Games page.

> **Hardware:** a Sipeed Tang Nano 20K and a **Raspberry Pi Pico 2 W**. The firmware runs on the Pico 2 W only.

## Download

- `game20k-0.9.1-pico2w.zip`: the firmware for the Raspberry Pi Pico 2 W.
- `game20k-0.9.1-tangnano20k.zip`: one image for the Tang Nano 20K's flash with all eight cores.

Setup as in the [README](https://github.com/scullymi/game20k/blob/v0.9.1/README.md#quick-start) and `FLASHING.txt`. The SD card of 0.9.0 keeps working.

## Changes since 0.9.0

- After a game switch, RetroAchievements starts a session for the new game, and no banner of the previous game stays on screen (#19).
- The Games page reads the card only when a ROM file is uploaded, deleted or renamed, and the selection stays on its game. The log no longer gets a line per menu tick while the page is open (#21).
- Ghosts'n Goblins: jotego's fix for the 6809 CPU's SYNC, CWAI and SWI instructions.
- The free toolchain gives the same bitstreams on macOS and Linux, see [docs/OPEN-TOOLCHAIN.md](https://github.com/scullymi/game20k/blob/v0.9.1/docs/OPEN-TOOLCHAIN.md).
