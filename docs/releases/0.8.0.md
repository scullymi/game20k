Every core now builds with a free, open-source toolchain, and switching games or cores no longer restarts the Pico.

> **Hardware:** a Sipeed Tang Nano 20K and a **Raspberry Pi Pico 2 W**. The firmware runs on the Pico 2 W only.

## Download

- `game20k-0.8.0-pico2w.zip`: the firmware for the Raspberry Pi Pico 2 W.
- `game20k-0.8.0-tangnano20k.zip`: one image for the Tang Nano 20K's flash with all eight cores.

Setup as in the [README](https://github.com/scullymi/game20k/blob/v0.8.0/README.md#quick-start) and `FLASHING.txt`. The SD card of 0.7.0 keeps working.

## Free toolchain

All eight cores build with Yosys, nextpnr and Apicula, from the same sources as the Gowin build, and all of them have been tested on the board. No Gowin licence or login is needed, see [docs/OPEN-TOOLCHAIN.md](https://github.com/scullymi/game20k/blob/v0.8.0/docs/OPEN-TOOLCHAIN.md).

This release's image is still built with the Gowin tools. From the next release on, the images come from the free toolchain. The Gowin build stays available as an option.

## Changes since 0.7.0

- A game or core switch keeps WiFi and the RetroAchievements login, the Pico no longer restarts.
- RetroAchievements through rcheevos 12.5. The banner at game start names the mode once and says when a DIP switch differs from what the set expects. It sits on a black box, readable on bright pictures.
- `config.ini`: a fixed network address can name its DNS server.
- SD card reads are checked by CRC and retried.
- 1943 and Ghosts'n Goblins: the YM2203's SSG channels at the levels of the real chip, from jt49.
- 1943 Mark II no longer reports a read outside the RAM mirror.
