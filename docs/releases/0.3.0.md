The two-game release: Pac-Man joins Galaga, the menu switches between them, and the bitstreams come with the release.

> **Hardware:** a Sipeed Tang Nano 20K and a **Raspberry Pi Pico 2 W**. The firmware runs on the Pico 2 W only.

## Download

- `game20k-0.3.0-pico2w.zip` holds `game20k-0.3.0-pico2w.uf2`, the firmware for the Raspberry Pi Pico 2 W, and its `NOTICE.txt`. GitHub Actions built both from the sources at this tag. The SHA-256 sums are at the end, and `gh attestation verify game20k-0.3.0-pico2w.zip -R scullymi/game20k` checks where the zip comes from.
- `game20k-0.3.0-tangnano20k.zip` holds the bitstreams for the Tang Nano 20K, Galaga and Pac-Man, with `FLASHING.txt`, `NOTICE.txt` and `SHA256SUMS`. They were built from the same tag with Gowin EDA Education, which GitHub Actions does not have. Apart from a table with Pac-Man's sound PROM in MikeJ's core, they hold no ROM image.

## Getting started

1. Prepare the SD card with your own ROM sets and `config.ini`, see [README, steps 2 and 3](https://github.com/scullymi/game20k/blob/v0.3.0/README.md#2-roms).
2. Write both bitstreams into the Tang Nano 20K's flash with the commands in `FLASHING.txt`, then power the board off and on.
3. Hold BOOTSEL on the Pico 2 W, plug it in and copy the `.uf2` to the drive that appears.

## Status

Galaga and Pac-Man run with picture, sound, the OSD menu and RetroAchievements, Puck Man on the Pac-Man board. Until RetroAchievements approves this client, unlocks count as softcore and leaderboard entries are not stored.

## Changes since 0.2.0

- Pac-Man as the second game, and Puck Man on the same board with the Perfect Pac subset of RetroAchievements.
- Game switch: a ROM of the other game picked in the menu loads its core from the board's flash and starts it. A ROM of the same board restarts into its game, a ROM the core cannot use is refused and the game keeps running.
- Larger achievement sets: up to 64 KB. A set that stays incomplete for lack of memory switches to softcore and says so.
- Pac-Man: no buzz next to the tones, and he no longer turns back and forth when a direction flickers in a corner of the stick.
- The network popup is gone, the menu shows the IP address under `Status` → `Network`.
- Bluetooth and USB network adapters are disabled in the Pico 2 W image.
