Update the cores and the firmware together. The 0.9.3 firmware needs the 0.9.3 cores.

Downloads as in 0.9.2, setup in the [README](https://github.com/scullymi/game20k/blob/v0.9.3/README.md#quick-start). The SD card of 0.9.2 keeps working.

## Changes since 0.9.2

- The cores no longer drop a byte at the end of a transfer from the Companion, so the firmware no longer waits after each one (#41).
- Ghosts'n Goblins: the core meets its clock with more margin (#43).
- `g20k.py` covers every step: `sdcard` prepares the SD card, `flash --download` and `firmware --download` use the files of a release (#36).
- On Windows, flashing the Nano needs the WinUSB driver, see [docs/windows-usb.md](https://github.com/scullymi/game20k/blob/v0.9.3/docs/windows-usb.md) (#39).
- The documentation is reorganized, each topic in one place (#45), and the gallery shows all games.
