## Changes since 0.9.4

- Cores and ROM files can also come from a USB drive: with the BL616 a core from the drive's `cores/` folder, with either Companion the ROM files in its `roms/` folder. See [docs/games.md](https://github.com/scullymi/game20k/blob/v0.9.5/docs/games.md#changing-the-game) and [docs/bl616.md](https://github.com/scullymi/game20k/blob/v0.9.5/docs/bl616.md#cores-and-roms-on-a-usb-drive) (#53, #54, #61).
- BL616: a core switch jumps straight to the core's slot in the flash instead of walking the ring (#55, #56).
- The `Games` page shows `no core` for a game whose core is missing from the flash and, with the BL616, from the USB drive (#56).
- `g20k.py flash --cores` writes any cores in any order. The cores zip holds each core's file for it (#57).
- The firmware is based on FPGA-Companion 1.4.36. Menus load faster, and a `config.xml` with an empty value no longer crashes the Companion (#51, #58, #59, #60).
- BL616: unplugging a keyboard no longer frees the joystick slot of a gamepad that stays plugged in (#60).
- A start game from a USB drive stays after `Save settings` (#61).

**Full Changelog**: https://github.com/scullymi/game20k/compare/v0.9.4...v0.9.5
