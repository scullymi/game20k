Pac-Man Plus and Ponpoko join, and a Games page in the menu lists every game on the card.

> **Hardware:** a Sipeed Tang Nano 20K and a **Raspberry Pi Pico 2 W**. The firmware runs on the Pico 2 W only.

## Download

- `game20k-0.7.0-pico2w.zip`: the firmware for the Raspberry Pi Pico 2 W.
- `game20k-0.7.0-tangnano20k.zip`: one image for the Tang Nano 20K's flash with all eight cores.

Setup as in the [README](https://github.com/scullymi/game20k/blob/v0.7.0/README.md#quick-start) and `FLASHING.txt`. **Rebuild the SD card with `scripts/make_sdcard.sh`:** every ROM file now ends with a footer, and the firmware turns away the files of earlier releases. Pac-Man Plus and Ponpoko need `pacplus.zip` and `ponpoko.zip`, see [roms/README.md](https://github.com/scullymi/game20k/blob/v0.7.0/roms/README.md).

## Changes since 0.6.1

- Pac-Man Plus and Ponpoko on the Pac-Man core, both with RetroAchievements.
- `Games`, the first entry of the menu, lists the games on the card by title, with the running game selected, and starts the one you pick, switching the core if needed. `Save settings` makes it the game that starts at power-on.
- Every ROM file ends with a footer that names the game and holds a checksum of its content. The Pico checks it while loading and stops a damaged file. Without a game in the core, RetroAchievements stays off and says `RA: NO GAME`.
- The FPGA takes any ROM file up to the size of its core's layout, the firmware checks the rest.
