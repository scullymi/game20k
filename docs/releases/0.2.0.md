The RetroAchievements release: a session with Rich Presence, the achievement list in the menu, leaderboards, and hardcore as the default with the protections it needs. It also fixes HDMI sound that could stay silent after loading the bitstream.

## Download

`game20k-0.2.0-pico2w.zip` holds

- `game20k-0.2.0-pico2w.uf2`, the firmware for the Raspberry Pi Pico 2 W, and
- `NOTICE.txt`, the licences of all software in the image.

GitHub Actions built both from the sources at this tag. The SHA-256 sums are at the end, and `gh attestation verify game20k-0.2.0-pico2w.zip -R scullymi/game20k` checks the build provenance.

The image runs on a Raspberry Pi Pico 2 W only.

## Getting started

1. Prepare the SD card with your own ROM set and `config.ini`, see [README, steps 2 and 3](https://github.com/scullymi/game20k/blob/v0.2.0/README.md#2-roms).
2. Hold BOOTSEL on the Pico 2 W, plug it in and copy the `.uf2` to the drive that appears.

The Tang Nano 20K needs its bitstream as well. This release does not include one, [THIRD-PARTY.md](https://github.com/scullymi/game20k/blob/v0.2.0/THIRD-PARTY.md#not-distributed) explains why. Build and flash it from this tag as [README, step 4](https://github.com/scullymi/game20k/blob/v0.2.0/README.md#4-fpga-build-and-flash) describes. **Update both together:** the RAM mirror changed, and this firmware refuses the 0.1.x bitstream with the banner `SYS: CORE TOO OLD`.

## Status

Galaga runs with picture, sound, the OSD menu, landscape or portrait output and RetroAchievements. Hardcore mode works on the device. Until RetroAchievements approves this client, the server keeps its unlocks as softcore and no leaderboard entries, and in hardcore the banner shows the server's warning "Unknown Emulator". The [README](https://github.com/scullymi/game20k/blob/v0.2.0/README.md#status) lists what works and what is open.

## Changes since 0.1.1

- RetroAchievements: a session with a Rich Presence ping every two minutes, the achievement list with progress in the menu, a challenge marker next to the picture, and leaderboards.
- Hardcore and softcore under `RetroAchievements` → `Mode` in the menu, hardcore by default. Switching to hardcore resets the game, and the banner names the mode at each game start. In hardcore the server's warning follows while RetroAchievements has not approved this client.
- Hardcore protection: a device key in the Pico's flash tags the unlocks waiting on the card and the cached achievement set, only a ROM with a known SHA-256 plays in hardcore, DIP switches reach the core only in a reset, and FTP cannot change `config.ini` or the `ra_*` files in hardcore.
- A leaderboard entry the server did not keep shows `RA: LB NOT RECORDED` instead of a rank.
- HDMI: every data island starts its packet counter at 0. Before, a sync that landed inside an island could leave the sound silent, with a normal picture, until the bitstream was loaded again.
- The RAM mirror has layout 3, with the challenge marker and the DIP switch state.
- [PRIVACY.md](https://github.com/scullymi/game20k/blob/v0.2.0/PRIVACY.md) lists what the device sends and stores.
- Host tests, checks of the contracts between core, firmware and scripts, and a checks workflow in GitHub Actions.
